Frequently Asked Questions


      

        How do I enter a binary tree?
        

          Type node values in level order, separated by commas or spaces, e.g. 1,2,3,4,5.
          The first value is the root, the next two are its children, and so on level by level.
        

      


      

        How do I mark an empty (missing) node?
        

          Use N, null, None or #. Example:
          1,2,3,N,5 means node 2 has no left child, only a right child 5.
        

      


      

        Is this the same format LeetCode uses?
        

          Yes. LeetCode-style arrays like [1,null,2,3] work after removing the brackets,
          so you can paste test cases straight from a problem.
        

      


      

        What does "Copy with spaces" do?
        

          It copies the ASCII tree exactly as shown, with every space kept. Paste it into any
          monospace editor and the branches stay aligned.
        

      


      

        Why does my pasted tree look crooked?
        

          The target app uses a proportional font. Switch to a monospace font such as Consolas or
          Courier New, or paste inside a code block.
        

      


      

        Can I change how the tree looks?
        

          Yes. Open the settings under the tree to change orientation, node shape, link shape, node
          radius and colour mode.
        

      


      

        Does it work for binary search trees?
        

          Yes. Any binary tree works, including BSTs. The visualizer draws the structure you enter
          and does not reorder values.
        

      


      

        Is my input saved or sent anywhere?
        

          No. Everything runs in your browser. Refreshing the page clears the tree.
